# 02 软件架构

## 六层结构（上为应用，下为硬件）

依赖只允许向下：页面不碰寄存器；Model 不直接读驱动。

```
L6  Pages (MVP) + PageManager + StatusBar + ResourcePool
L5  DataProc 节点 + DataCenter 发布/订阅 + StorageService
L4  LVGL v8 + lv_port（显示 / 编码器 / SdFat）
L3  HAL 接口（App/Common/HAL），只有声明
L2  ArduinoAPI + Libraries（ST7789 / TinyGPSPlus / SdFat / IMU / MAG）
L1  Platform/Core（时钟、SPI、ADC、RTC、PWM、看门狗）
```

对应目录：

| 层 | 路径 |
|----|------|
| 应用 UI | `USER/App/Pages` |
| 业务数据 | `USER/App/Common/DataProc` |
| HAL 接口 | `USER/App/Common/HAL` |
| MCU HAL 实现 | `USER/HAL` + `MDK-ARM_F4xx/Platform/HAL` |
| 模拟器 HAL | `Simulator/LVGL.Simulator/HAL` |
| LVGL 移植 | `USER/lv_port`，显示刷新在 Platform 的 `lv_port_disp.cpp` |
| 驱动 | `Libraries/` |
| MCU 外设 | `MDK-ARM_F435/Platform/Core` |

HAL 接口写在应用层，实现按平台替换。这是同一套 App 能跑 MCU / VS / Linux 的原因。

## 启动链路

入口：`Software/X-Track/USER/main.cpp`

```
Core_Init()
  -> HAL::HAL_Init()           电源、背光、编码器、RTC、GPS、传感器、SD、显示、看门狗
  -> lv_init() + lv_port_init()
  -> App_Init()                DataProc、加载 JSON、资源池、状态栏、装页面、Push Startup
  -> loop:
        HAL::HAL_Update()
        lv_task_handler()
        __wfi()
```

`App_Init()` 关键步骤（`USER/App/App.cpp`）：

1. `DataProc_Init()`
2. 通知 Storage / SysConfig 执行 LOAD
3. 初始化资源池、顶层 StatusBar
4. `manager.Install(...)` 安装页面
5. `manager.Push("Pages/Startup")`

关机：`HAL::Power_SetEventCallback(App_Uninit)`，保存 SysConfig / Storage，停止 Recorder。

开机动画结束后，Startup 页 `Replace("Pages/Dialplate")` 进入主表盘。

## 两套调度

无 RTOS，两套定时源并行。

### HAL 侧：MillisTaskManager

注册在 `USER/HAL/HAL.cpp`：

| 任务 | 周期 |
|------|------|
| Power_EventMonitor | 100 ms |
| GPS_Update | 200 ms |
| SD_Update | 500 ms |
| IMU / MAG_Update | 1000 ms |
| Memory_DumpInfo | 1000 ms |
| 看门狗喂狗 | 超时 / 10 |

另有 10 ms 硬件定时器中断：Power、Encoder、Audio。

### App 侧：LVGL timer

DataCenter 的 Account 定时回调走 `lv_timer`，在 `lv_task_handler()` 里执行。

| 节点 | 周期 |
|------|------|
| DP_GPS | MCU 1000 ms；模拟器 10 ms |
| DP_SportStatus | 500 ms |
| DP_Power | 500 ms |
| 各页面 Update | 页面自己创建（表盘 1000 ms） |

## 配置落点

| 文件 | 内容 |
|------|------|
| `USER/App/Config/Config.h` | 默认经纬度、体重、地图路径、录轨目录 |
| `USER/HAL/HAL_Config.h` | 引脚、传感器开关、看门狗、屏幕 240x240 |
| SD 卡 `/SystemSave.json` | 运行时：里程、时区、地图源、坐标系、上次位置 |
