## MVP：一类页面三份文件

以表盘为例：

```
Pages/Dialplate/
├── Dialplate.h / Dialplate.cpp     Presenter：生命周期 + 交互
├── DialplateView.h / .cpp          View：只建 LVGL 控件
└── DialplateModel.h / .cpp         Model：只和 DataCenter 说话
```

C 语言逐文件实现说明：

- [10-Dialplate-View-C语言.md](10-Dialplate-View-C语言.md)
- [11-Dialplate-Model-C语言.md](11-Dialplate-Model-C语言.md)
- [12-Dialplate-Presenter-C语言.md](12-Dialplate-Presenter-C语言.md)


| 角色 | 允许做 | 不允许做 |
|------|--------|----------|
| View | 创建控件、样式、动画 | 订阅数据、调用 HAL |
| Model | Subscribe / Pull / Notify | 操作具体 lv_obj |
| Presenter | 粘合两者、页面跳转、UI 状态机 | 直接读传感器寄存器 |

`Dialplate.cpp` 里 `onRecord()` 的 READY / RUN / PAUSE / STOP 是 UI 状态；真正开录是 `Model.RecorderCommand()`。

模板：`USER/App/Pages/_Template/`。

## 已有页面

| 页面 ID | 类名 | 职责 |
|---------|------|------|
| Pages/Startup | Startup | 开机动画，结束后 Replace 到表盘 |
| Pages/Dialplate | Dialplate | 主界面：速度、里程、录轨 |
| Pages/LiveMap | LiveMap | 离线瓦片 + 航向 + 实时轨迹 |
| Pages/SystemInfos | SystemInfos | GPS / IMU / 电源 / SD / 版本 |
| Pages/_Template | Template | 脚手架 |
| （顶层 overlay） | StatusBar | 不是页面，画在 `lv_layer_top` |

六个文件夹各自干什么、怎么跳转：[15-六个文件夹的业务.md](15-六个文件夹的业务.md)。

安装与跳转在 `App.cpp`：`Install` 后 `Push("Pages/Startup")`。
页面内跳转：`_Manager->Push("Pages/LiveMap")` 等。

工厂：`Pages/AppFactory.cpp` 用 `APP_CLASS_MATCH` 按类名 new 页面。

## PageManager 生命周期

完整对照源码见 [14-PageManager-C语言.md](14-PageManager-C语言.md)。下面只保留状态顺序和表盘对照。

状态机（`Utils/PageManager/PageBase.h`）：

```
IDLE
 -> LOAD            onViewLoad / onViewDidLoad
 -> WILL_APPEAR     onViewWillAppear
 -> DID_APPEAR      onViewDidAppear
 -> ACTIVITY
 -> WILL_DISAPPEAR  onViewWillDisappear
 -> DID_DISAPPEAR   onViewDidDisappear
 -> UNLOAD          onViewUnload / onViewDidUnload
```

表盘把资源钉在对应阶段（值得对照着读）：

| 回调 | 表盘在做什么 |
|------|----------------|
| onViewLoad | `Model.Init()` + `View.Create(_root)` + 绑事件 |
| onViewWillAppear | 编码器 group、恢复焦点、刷新一次、出现动画 |
| onViewDidAppear | 创建 1s 刷新 timer |
| onViewWillDisappear | 记住焦点、清空 group、删 timer |
| onViewUnload | `Model.Deinit()` + `View.Delete()` |

另外支持：页面缓存、Push / Pop / Replace、切换动画、根节点拖拽。

## 新增一页的固定步骤

1. 复制 `Pages/_Template`，改类名与文件名
2. `AppFactory.cpp` 增加 `APP_CLASS_MATCH`
3. `App.cpp` 里 `manager.Install(...)`
4. `Model::Init` 里 `new Account` 并 Subscribe 所需节点
5. 需要新数据：在 `DP_LIST.inc` 加节点，不要在 View 里读 HAL
