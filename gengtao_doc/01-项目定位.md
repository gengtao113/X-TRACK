# 01 项目定位

## 结论

这是 **单片机固件项目**，不是 Linux 应用项目。

- 主控：AT32F435CGU7（288MHz，RAM 512KB，Flash 1MB），亦可 AT32F403A
- GUI：LVGL v8，屏幕 ST7789 IPS 240x240
- 输入：旋转编码器
- 无 RTOS：主循环合作式调度，空闲 `__wfi()`

裸机主循环、两套调度、10ms 中断如何配合，见：[13-裸机框架-C语言.md](13-裸机框架-C语言.md)。

Linux / Windows 目录是 **同一套 `USER/App` 的移植**，用来脱离硬件调界面。Linux 移植明确写了：关机自动保存不支持，轨迹记录可能不可用。产品功能以 MCU 固件为准。

如何在本机 Linux 编译运行，见：[19-Linux上运行.md](19-Linux上运行.md)。桌面推荐 `LinuxSDL2`。

## 产品做什么

开源 GPS 自行车码表：

- 速度、距离、时间、卡路里、航向
- 离线地图 + 实时位置 + 缩放
- 轨迹记录，导出 GPX
- 计步（LSM6DSM）、地磁（LIS3MDL，可选）
- GPS 校准 RTC，掉电保存 JSON

## 四套运行时

| 目标 | 工程路径 | 编译 |
|------|----------|------|
| 真机 F435 | `Software/X-Track/MDK-ARM_F435` | Keil >= 5.25，ARM Compiler 5 + 指定 Pack |
| 真机 F403A | `Software/X-Track/MDK-ARM_F403A` | 同上，栈更紧 |
| Windows 模拟器 | `Software/X-Track/Simulator` | VS2019，Release x86 |
| Linux framebuffer | `Software/X-Track/Linux` | `make -j`，evdev + fb |
| Linux SDL2 | `Software/X-Track/LinuxSDL2` | `./gengtao_build.sh`（CMake） |

Keil 注意：不要随便改芯片选型。启动文件会重生，默认栈太小会立刻 HardFault。Pack 必须用 `Software/Pack` 里的指定版本。
