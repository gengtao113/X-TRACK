# 15 六个文件夹的业务（C 语言）

路径：`USER/App/Pages/` 下这六个目录。  
它们一起构成码表的全部界面；**不是六个平等的页面**。

| 文件夹 | 是不是 PageManager 页面 | 产品角色 |
|--------|--------------------------|----------|
| StartUp | 是 | 开机闪屏，用完扔掉 |
| Dialplate | 是 | 骑行主界面（根页） |
| LiveMap | 是 | 从表盘推进的地图 |
| SystemInfos | 是 | 从表盘推进的诊断列表 |
| StatusBar | **否** | 顶层常驻条，所有页共享 |
| _Template | 是（已 Install，产品路径用不到） | 复制用脚手架 |

调度细节见 [14-PageManager-C语言.md](14-PageManager-C语言.md)。  
表盘三文件细拆见文档 10 / 11 / 12。

---

## 1. 它们怎么串起来

`App.cpp` 启动时：

1. `StatusBar_Create(lv_layer_top())` —— 画在 LVGL 顶层，不进页面栈
2. `Install` 五个页面进池
3. `Push("Pages/Startup")`

之后用户路径：

```
开机
  -> StartUp（2 秒，关编码器，播 Logo）
  -> Replace Dialplate          栈里只剩表盘
        |-- 地图键 Push LiveMap     返回 Pop
        `-- 菜单键 Push SystemInfos 返回 Pop
```

StatusBar 全程盖在上面。开机阶段先藏着，StartUp 离开时 `Notify` 让它滑出来。

C 里记三件事就够：

- StartUp 用 **Replace**，不当栈底
- Dialplate 是 **根页**，不能 Pop
- LiveMap / SystemInfos 只 **Pop**，不管底下是谁

---

## 2. StatusBar：不是页面的页面

源码：`Pages/StatusBar/`（只有 `.h` / `.cpp`，没有 View/Model 三分）。

它同时干两件事：

1. **UI**：卫星数、SD 卡图标、时钟、REC 文字、电池
2. **总线节点**：`DATA_PROC_INIT_DEF(StatusBar)`，账号名叫 `"StatusBar"`

所以别的 Model 可以 `Notify("StatusBar", ...)`，它自己也可以 `Pull("GPS")`。

创建：`App_Init` 里挂到 `lv_layer_top()`，高度约 25 像素。  
自己有 LVGL timer，周期刷新：

| 显示 | Pull 谁 |
|------|---------|
| 卫星颗数 | GPS |
| SD 是否插入 | Storage |
| 时:分 | Clock |
| 电量 / 充电动画 | Power |

别人给它发的命令（`EVENT_NOTIFY`）：

| cmd | 谁在用 | 效果 |
|-----|--------|------|
| `APPEAR` | StartUp 离开时 | 状态栏滑入/滑出 |
| `SET_STYLE` | Dialplate 透明；地图/系统信息黑底 | 换背景风格 |
| `SET_LABEL_REC` | Dialplate 录轨状态机 | 显示 REC / PAUSE / STOP / 空白 |

**没有生命周期回调**，不走 Push/Pop。页面切走它还在。

## 3. StartUp：开机动画，2 秒后让位

MVP 齐全，但 Model 很瘦。

| 时机 | 业务 |
|------|------|
| `onCustomAttrConfig` | 关缓存、无切页动画（播完就卸） |
| `onViewLoad` | 关编码器，避免闪屏时拧旋钮；建 Logo；**一次性** 2s timer |
| `onViewWillAppear` | 播 `"Startup"` 提示音，开 Logo 时间轴 |
| `onViewDidAppear` | root 淡出（1.5s 后开始，持续 0.5s） |
| 2s timer | `Replace("Pages/Dialplate")` |
| `onViewDidDisappear` | 通知状态栏出现 |
| `onViewUnload` | 编码器重新打开 |

View：一个 Logo 标签 + 入场时间轴。  
Model：只 Subscribe `MusicPlayer`、`StatusBar`。  
`SetEncoderEnable` 直接调 `HAL::Encoder_SetEnable`，这是本仓库里少见的「Model 碰 HAL」，因为开机时总线还没必要绕一圈。

产品含义：挡住初始化、播品牌动画，然后把栈交给表盘。

## 4. Dialplate：骑行主界面

产品核心。三键：

| 按钮 | 操作 | 业务 |
|------|------|------|
| 地图 | 短按 | `Push("Pages/LiveMap")` |
| 菜单 | 短按 | `Push("Pages/SystemInfos")` |
| 录轨 | 长按 / 短按 | 界面状态机 READY→RUN→PAUSE→STOP，命令发给 Recorder |

1 秒 timer 刷：时速、均速、单次时间、里程、卡路里。数据来自 Model 缓存的 `SportStatus`。

录轨规则（界面状态，不是 GPX 文件状态）：

```
READY  长按且 GPS 有星 -> REC_START，图标 pause
RUN    短按           -> REC_PAUSE
PAUSE  短按继续 / 长按进入预备 STOP
STOP   短按继续 / 长按 REC_STOP 回 READY
```

`REC_READY_STOP` 只改状态栏文字 `"STOP"`，还不关文件。

缓存默认开：去地图再回来，不必重建控件。切页动画 `NONE`。

细读：文档 10 / 11 / 12。

## 5. LiveMap：离线地图 + 轨迹

从表盘推进，返回就 Pop。**关缓存**（瓦片和折线占 RAM）。

和表盘一个重要差别：`Model.Init()` 放在 `onViewWillAppear`，`Deinit()` 放在 `onViewDidDisappear`。  
页面对象还在池里，但总线账号随显示开关，避免地图不在前台还挂着订阅。

100ms timer，真正按 GPS 刷新周期（配置宏）才 `CheckPosition`：

1. Pull GPS（无效则用 SysConfig 里的默认经纬度）
2. 经纬度 → 地图像素（`MapConv`）
3. 算当前要哪几块 256×256 瓦片（`TileConv`）
4. 瓦片容器变了就换图
5. 若 TrackFilter 在录（表盘已开始录轨），把点抽稀后画折线

同时刷一小块运动信息（速度等，用 SportStatus 缓存）。

交互：

- 编码器编辑缩放滑条，改地图级别（静态变量记住，下次进来还是这个级别）
- 3 秒无操作隐藏缩放条
- `LEAVE`、按缩放条、按运动信息区 → `Pop`

View 负责瓦片容器、箭头、轨迹线、缩放条、信息条。  
Model 还带着三个算法对象：`mapConv` / `tileConv` / 点线滤波器，不完全是「纯总线」，因为坐标换算属于本页业务。

## 6. SystemInfos：只读诊断页

从表盘菜单进入。滚动列表，八组：

| 组 | 数据来源（Model Pull） |
|----|------------------------|
| Sport | SportStatus：里程、时间、极速 |
| GPS | 经纬高、UTC、航向、速度 |
| MAG | 磁力计方向和 XYZ |
| IMU | 步数等 |
| RTC | 时钟日期时间 |
| Battery | 电量、电压、充电状态 |
| Storage | SD 是否在、容量、文件系统版本 |
| System | 固件名、作者、LVGL 版本、运行时间、编译器、编译时刻 |

1 秒 timer 全量刷新。状态栏改黑底。  
编码器在组之间换焦；**已聚焦的图标再按一下**，或 root 收到 `LEAVE`，就 `Pop`。

这页几乎没有「命令」：Model 全是 GetXxx，外加改状态栏样式。适合当「总线 Pull 百科」。

## 7. _Template：脚手架，不是骑行功能

已经 `Install("Template", "Pages/_Template")`，工厂能 `new`，但 **没有任何正式页面 Push 它**。

它示范的是框架用法，不是业务：

- `SetCustomCacheEnable(true)` + 底部弹入动画
- `PAGE_STASH_POP` 取背景色和 timer 周期（没有 stash 就用默认白底、1s）
- Model 只有 `lv_tick_get()`，证明「Model 可以极瘦」
- 点空白或 LEAVE → Pop

新加一页：复制这个文件夹，改类名，工厂加 `APP_CLASS_MATCH`，`App.cpp` 里 `Install`，再从某页 `Push`。

## 9. 建议阅读顺序

1. `_Template`：看空壳生命周期（不必抠业务）
2. `StartUp`：最短的真实页，看 Replace 和关编码器
3. `Dialplate`：主业务 + 录轨状态机（已有文档 10–12）
4. `StatusBar`：弄清「不是页面也能挂总线」
5. `SystemInfos`：大量 Pull，结构重复好跟
6. `LiveMap`：最后看，瓦片和轨迹滤波器最重

源码入口：

```
Pages/AppFactory.cpp          五个类名
App.cpp                       Install + Push Startup + 创建 StatusBar
Pages/StartUp/StartUp.cpp     2s Replace
Pages/Dialplate/Dialplate.cpp 三键 + 录轨
Pages/LiveMap/LiveMap.cpp     100ms 刷新地图
Pages/SystemInfos/SystemInfos.cpp  八组 Get + Pop
Pages/StatusBar/StatusBar.cpp 顶栏 UI + 总线命令
Pages/_Template/Template.cpp  复制起点
```
