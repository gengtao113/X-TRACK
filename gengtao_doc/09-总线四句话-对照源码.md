# 09 总线四句话：对照源码的 C 写法

本文只展开 `07-数据流-C语言说明.md` 结尾那两句：

> 硬件只进一个 Account；页面用名字 Subscribe/Pull/Notify，互不 include。  
> Publish 是推缓存，Pull 是当场要一份，Notify 是下命令，Timer 是节点自己的周期任务。

对应 C++ 仍在工程里，下面全部改写成 C。读的时候打开这几个文件即可：

| 原则 | 源码 |
|------|------|
| 硬件只进一个节点 | `DP_GPS.cpp` 调 `HAL::GPS_GetInfo`；全工程 App 层几乎只这里读 GPS |
| 用名字、互不 include | `DialplateModel.cpp` 的 `Subscribe("GPS")`，没有 `#include "DP_GPS.h"` |
| Publish 推缓存 | `Account::Commit` + `Publish`，`DP_GPS.cpp` 卫星>=3 时调用 |
| Pull 当场要一份 | `DialplateModel::GetGPSReady` -> `account->Pull("GPS", ...)` |
| Notify 下命令 | `DialplateModel::RecorderCommand` -> `Notify("Recorder", ...)` |
| Timer 周期任务 | `SetTimerPeriod` + `onEvent` 里 `EVENT_TIMER` |

---

## 0. 先有一张「按名字找人」的表

`DataProc.cpp` 里全局一个中心，每个节点一个 Account，名字就是字符串 `"GPS"`。

C++：

```c
static DataCenter center("CENTER");
new Account("GPS", &center, sizeof(HAL::GPS_Info_t));
```

C：

```c
typedef struct Account Account;

struct Account {
    const char *id;
    Account **subs;     /* 谁订阅了我 */
    int n_sub;
    Account **pubs;     /* 我订阅了谁 */
    int n_pub;
    int (*on_event)(Account *self, int event, Account *from, void *data, uint32_t size);
    uint8_t *cache[2];  /* 乒乓，buf_size==0 则没有 */
    uint32_t buf_size;
    void *user;
};

Account *center_find(const char *id);   /* 在中心列表里 strcmp */
```

`Subscribe("GPS")` 不 include GPS 的 .h，只按字符串找指针，两边数组互记：

```c
int Account_Subscribe(Account *me, const char *pub_id)
{
    Account *pub = center_find(pub_id);
    me->pubs[me->n_pub++] = pub;
    pub->subs[pub->n_sub++] = me;
    return 0;
}
```

对应源码 `Account.cpp` 的 `Subscribe`：`publishers.push_back(pub)` 和 `pub->subscribers.push_back(this)`。

表盘 Model 因此可以只写：

```c
Account_Subscribe(m->acc, "SportStatus");
Account_Subscribe(m->acc, "GPS");
Account_Subscribe(m->acc, "Recorder");
Account_Subscribe(m->acc, "StatusBar");
Account_Subscribe(m->acc, "MusicPlayer");
```

它不知道 GPS 节点的函数名，只知道名字 `"GPS"`。换 GPS 实现时，改 `DP_GPS.c` 即可，表盘不用动。

## 1. 硬件只进一个 Account

全工程搜 `HAL::GPS_GetInfo`：实现在 `HAL_GPS.cpp`，**调用方在 App 层只有 `DP_GPS.cpp` 两处**（定时采集、被 Pull 时现读）。

表盘、地图用的是类型 `HAL::GPS_Info_t` 和 `Pull("GPS")`，**不调 HAL**。

C 里应写成硬规矩：

```c
/* 只允许 dp_gps.c 包含并调用 */
#include "hal_gps.h"

void HAL_GPS_GetInfo(GPS_Info_t *out);

/* dp_gps.c */
static int gps_on_event(Account *self, int event, Account *from, void *data, uint32_t size)
{
    if (event == EVENT_TIMER) {
        GPS_Info_t gps;
        HAL_GPS_GetInfo(&gps);          /* 唯一入口 */
        /* ... Commit+Publish 见下一节 */
        return 0;
    }
    if (event == EVENT_PULL) {
        if (size != sizeof(GPS_Info_t))
            return -2;
        HAL_GPS_GetInfo((GPS_Info_t *)data);  /* Pull 时也只在这里读硬件 */
        return 0;
    }
    return -3;
}
```

`dialplate_model.c` 禁止 `#include "hal_gps.h"`。这就是「硬件只进一个 Account」。

## 2. Publish：推缓存（先 Commit 再广播）

卫星够了才推。源码：

```c
/* DP_GPS.cpp */
if (satellites >= 3) {
    account->Commit(&gpsInfo, sizeof(gpsInfo));
    account->Publish();
}
```

`DP_LIST.inc` 里 `DP_DEF(GPS, sizeof(HAL::GPS_Info_t))`，创建时就分配了两块等长缓冲。

Commit = 写当前写指针，翻乒乓：

```c
int Account_Commit(Account *pub, const void *src, uint32_t size)
{
    if (size != pub->buf_size)
        return -1;
    memcpy(pub->cache[write_idx], src, size);
    pingpong_write_done(pub);
    return 0;
}
```

Publish = 取出只读那一块，**同步**调每个订阅者的回调（不是另起线程）：

```c
#define EVENT_PUBLISH  1

int Account_Publish(Account *pub)
{
    void *rbuf = pingpong_get_read(pub);
    int i;
    for (i = 0; i < pub->n_sub; i++) {
        Account *sub = pub->subs[i];
        if (sub->on_event)
            sub->on_event(sub, EVENT_PUBLISH, pub, rbuf, pub->buf_size);
    }
    return 0;
}
```

对应 `Account::Publish`：`param.event = EVENT_PUB_PUBLISH`，`param.data_p = rBuf`，然后 `callback(sub, &param)`。

表盘收到推送后只 memcpy，不读串口：

```c
/* 对应 DialplateModel::onEvent */
static int model_on_event(Account *self, int event, Account *from, void *data, uint32_t size)
{
    DialplateModel *m = self->user;

    if (event != EVENT_PUBLISH)
        return -3;
    if (strcmp(from->id, "SportStatus") != 0)
        return -8;
    if (size != sizeof(SportStatus_Info_t))
        return -2;

    memcpy(&m->sport, data, size);   /* 推过来的是缓存指针，立刻拷走 */
    return 0;
}
```

注意：GPS 的 Publish 推的是 `GPS_Info_t`；表盘 Model 的回调里 **只处理 SportStatus**。速度数字来自 SportStatus 节点自己 Pull GPS、算完再 Publish。链路是：

```
TIMER: HAL_GPS_GetInfo -> GPS.Commit+Publish
SportStatus 的 TIMER: Pull("GPS") -> 算速度 -> SportStatus.Commit+Publish
DialplateModel.on_event: memcpy sportStatusInfo
Presenter 每秒 Update: lv_label 显示
```

Publish 的数据寿命：读缓冲在本次 for 循环内有效。订阅者必须 memcpy 走，不能把 `data_p` 存起来下次再用。

## 3. Pull：当场要一份（调发布者的回调）

表盘长按录轨前要立刻知道有没有星，不能等下一次 Publish。源码：

```c
bool DialplateModel::GetGPSReady()
{
    HAL::GPS_Info_t gps;
    if (account->Pull("GPS", &gps, sizeof(gps)) != Account::RES_OK)
        return false;
    return (gps.satellites > 0);
}
```

Pull 实现：先确认自己 Subscribe 过，再调 **发布者** 的 `on_event`，event 换成 PULL，`data_p` 是调用者自己的栈变量：

```c
#define EVENT_PULL  2

int Account_Pull(Account *me, const char *pub_id, void *dst, uint32_t size)
{
    Account *pub = find_in_my_pubs(me, pub_id);  /* 未订阅则失败 */
    if (!pub || !pub->on_event)
        return -7;
    return pub->on_event(pub, EVENT_PULL, me, dst, size);
}
```

GPS 节点在 PULL 分支里 **现读 HAL，填进 dst**（就是上面的 `&gps`）：

```c
    if (event == EVENT_PULL) {
        if (size != sizeof(GPS_Info_t))
            return -2;
        HAL_GPS_GetInfo((GPS_Info_t *)data);
        return 0;
    }
```

和 Publish 的差别：

| | Publish | Pull |
|--|---------|------|
| 谁主动 | 发布者 | 订阅者 |
| 数据从哪来 | 事先 Commit 的乒乓缓存 | 发布者回调里现填（GPS 是现读 HAL） |
| 调用者 | 无返回缓冲 | 自己准备 `GPS_Info_t gps` |
| 典型用途 | 1Hz 刷新速度 | 按键瞬间问「有没有星」 |

若发布者没注册回调，源码会退化为 `memcpy` 那块 Commit 缓存。GPS 注册了回调，所以走现读。

## 4. Notify：下命令（不是传传感器数据）

开始录轨不需要 GPS 结构体，需要一条命令。源码：

```c
account->Notify("Recorder", &recInfo, sizeof(recInfo));
account->Notify("StatusBar", &statInfo, sizeof(statInfo));
```

和 Pull 一样按名字找到对方，但 event 是 NOTIFY，对方通常当 switch(cmd) 用：

```c
#define EVENT_NOTIFY  3

int Account_Notify(Account *me, const char *pub_id, const void *cmd, uint32_t size)
{
    Account *pub = find_in_my_pubs(me, pub_id);
    return pub->on_event(pub, EVENT_NOTIFY, me, (void *)cmd, size);
}
```

对应 `Account::Notify`：`param.event = EVENT_NOTIFY`。

Recorder 节点的 C 骨架：

```c
typedef struct {
    int cmd;        /* START / PAUSE / STOP */
    uint16_t time;
} Recorder_Info_t;

static int recorder_on_event(Account *self, int event, Account *from, void *data, uint32_t size)
{
    Recorder_Info_t *info;

    if (event != EVENT_NOTIFY)
        return -3;
    if (size != sizeof(*info))
        return -2;

    info = data;
    switch (info->cmd) {
    case REC_START:  gpx_open();  break;
    case REC_PAUSE:  gpx_pause(); break;
    case REC_STOP:   gpx_close(); break;
    }
    return 0;
}
```

表盘 **不 include 文件系统、不写 GPX**。Notify 是命令，Publish/Pull 是数据。

同一套 Notify 还用来播提示音：`Notify("MusicPlayer", &info)`，`info.music = "Error"`。

前提：发送方必须先 `Subscribe("Recorder")`。未订阅会 `RES_NOT_FOUND`（源码 Pull/Notify 都先 `Center->Find(&publishers, pubID)`）。

## 5. Timer：节点自己的周期任务

GPS 初始化：

```c
account->SetEventCallback(onEvent);
account->SetTimerPeriod(CONFIG_GPS_REFR_PERIOD);  /* MCU 上 1000ms */
```

库把 Account 指针塞进 `lv_timer` 的 user_data。到期后不是直接调 `onTimer`，而是造一个 TIMER 事件再进同一个 `on_event`：

```c
#define EVENT_TIMER  4

static void account_timer_cb(lv_timer_t *t)
{
    Account *acc = t->user_data;
    acc->on_event(acc, EVENT_TIMER, acc, NULL, 0);
}
```

对应 `Account::TimerCallbackHandler`。

GPS 的 `onEvent` 第一分支就是：

```c
if (param->event == Account::EVENT_TIMER) {
    onTimer(account);
    return Account::RES_OK;
}
```

C 合并成：

```c
static int gps_on_event(Account *self, int event, Account *from, void *data, uint32_t size)
{
    if (event == EVENT_TIMER) {
        GPS_Info_t gps;
        HAL_GPS_GetInfo(&gps);
        if (gps.satellites >= 3) {
            Account_Commit(self, &gps, sizeof(gps));
            Account_Publish(self);
        }
        return 0;
    }
    if (event == EVENT_PULL) {
        HAL_GPS_GetInfo((GPS_Info_t *)data);
        return 0;
    }
    return -3;
}
```

Timer 是闹钟，到期后这个节点自己决定：读 HAL、Publish、或 Pull 别人再算。页面的 1 秒刷 Label 是 Presenter 自己的 `lv_timer`，和 Account Timer 不是同一个。

## 6. 四句话串成一次「长按录轨」

```c
void on_record_long_press(DialplatePage *d)
{
    GPS_Info_t gps;

    /* Pull：当场要一份 */
    if (Account_Pull(d->model.acc, "GPS", &gps, sizeof(gps)) != 0
        || gps.satellites == 0) {
        Music_Info_t m = { .name = "Error" };
        Account_Notify(d->model.acc, "MusicPlayer", &m, sizeof(m));
        return;
    }

    /* Notify：下命令 */
    Recorder_Info_t rec = { .cmd = REC_START, .time = 1000 };
    Account_Notify(d->model.acc, "Recorder", &rec, sizeof(rec));
}

/* 与按键无关、一直在跑： */
/* GPS 的 Timer -> Commit+Publish */
/* SportStatus 的 Timer -> Pull GPS -> Publish 速度 */
/* DialplateModel 收到 Publish -> memcpy */
/* Presenter 的 timer -> 写 Label */
```

页面文件始终没有 `#include "hal_gps.h"` / `#include "gpx.h"`。

## 7. 对照表（看到 C++ 就换成左边）

| C++ | C |
|-----|---|
| `account->Subscribe("GPS")` | 两边指针数组互记，按字符串查找 |
| `Commit(&x, sizeof(x))` | `memcpy` 到乒乓写缓冲 |
| `Publish()` | `for` 订阅者，`on_event(EVENT_PUBLISH, 读缓冲)` |
| `Pull("GPS", &gps, n)` | 调 GPS 的 `on_event(EVENT_PULL, &gps)` |
| `Notify("Recorder", &cmd, n)` | 调 Recorder 的 `on_event(EVENT_NOTIFY, &cmd)` |
| `SetTimerPeriod(1000)` | `lv_timer` 到期发 `EVENT_TIMER` |
| `param->tran->ID` | `from->id`，谁发来的 |
| `account->UserData` | `self->user`，还原 Model 指针 |

一句话：**名字当地址，回调当函数；推缓存、拉现货、发命令、自己闹钟，四种 event 共用一个 `on_event`。**
