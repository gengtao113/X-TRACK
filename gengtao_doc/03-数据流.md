# 03 数据流与 DataCenter

只用 C、不熟悉 C++ 时，请先看：[07-数据流-C语言说明.md](07-数据流-C语言说明.md)。


## 设计目的

页面不读 GPS 寄存器、不直接操作 SD。传感器、运动统计、录轨、状态栏都做成 DataCenter 上的 Account，用名字通信。

中心实例名：`CENTER`（`USER/App/Common/DataProc/DataProc.cpp`）。

## 四种通信

| 动作 | 方向 | 用途 |
|------|------|------|
| Publish | 发布者 -> 订阅者 | 推缓存（如 GPS 定位成功后广播） |
| Pull | 订阅者 -> 发布者 | 拉最新数据（如表盘查卫星数） |
| Notify | 订阅者 -> 发布者 | 发命令（开始/暂停录轨） |
| Timer | 节点自己 | 周期采集或结算 |

主账户 `AccountMain` 自动订阅全部子节点，用于开机 LOAD、关机 SAVE 这类全局命令。

## 节点注册

`USER/App/Common/DataProc/DP_LIST.inc` 用 X-Macro 列出节点；`DataProc.cpp` 两次 include：先 `new Account`，再调用 `_DP_xxx_Init`。

新增业务数据：加一个 `DP_xxx.cpp` + 在 `DP_LIST.inc` 写一行 `DP_DEF`，不要在 View 里读 HAL。

## 13 个节点

| 节点 | 缓存 | 角色 |
|------|------|------|
| Storage | 无 | JSON KV，加载/保存 `SystemSave.json` |
| Clock | 无 | RTC 读写，GPS 校时 |
| GPS | `GPS_Info_t` | 读 HAL；卫星 >= 3 才 Publish |
| Power | 无 | 电量/充电；关机回调 `App_Uninit` |
| SportStatus | `SportStatus_Info_t` | 速度、里程、卡路里；绑定 Storage |
| Recorder | 无 | GPX 写到 SD `Track/` |
| IMU | `IMU_Info_t` | 加速度/陀螺/计步 |
| MAG | `MAG_Info_t` | 地磁 |
| StatusBar | 无 | 状态栏样式、REC 标签 |
| MusicPlayer | 无 | 操作音 |
| TzConv | 无 | 时区 |
| SysConfig | 无 | 地图路径、坐标系、音效、默认经纬度 |
| TrackFilter | 无 | 拐点提取 + 可视区裁剪，喂给 LiveMap |

## 骑行主链路

```
HAL_GPS
   -> DP_GPS
        -> DP_SportStatus -> Dialplate（表盘数字）
        -> DP_Recorder    -> GPX 文件
                          -> DP_TrackFilter -> LiveMap（实时轨迹）
        -> DP_Clock（校时）
        -> LiveMap（实时位置）
```

表盘 Model 订阅：`SportStatus`、`Recorder`、`StatusBar`、`GPS`、`MusicPlayer`。
地图 Model 订阅：`GPS`、`SportStatus`、`TrackFilter`、`SysConfig`、`StatusBar`。

## 典型交互：表盘开始录轨

1. Presenter 判断长按 -> `Model.GetGPSReady()`（Pull GPS）
2. 未定位：Notify MusicPlayer 播 Error，直接返回
3. 已定位：Notify Recorder START，Notify StatusBar 显示 REC
